# Устранение флуда цитатами

Владелец показал мобильный экран: после одного сообщения агента идут четыре соседние цитатные сводки, первые три повторяют текст. Поручение: «Вот такого быть не должно у нас ненужного флуда цитатами». Основа — принятая [редакция кольца, точки, стрелки и итогового времени](2026-10-30-ring-arrow.md). Словарь принадлежит другому треду и не изменён.

## Подтверждённая причина

Исходный этап найден штатным поиском по заголовку и точной фразе сообщения. API разделял последовательность инструментов на runs внутренними reasoning-записями. В native интерфейсе часть reasoning входит в bundle и не имеет собственной видимой строки. Minus всё равно создавал цитату для каждого API run, хотя инструменты визуально шли подряд. Дополнительно native summary и следующий raw tool могли пересекаться при подсчёте: summary включала первый вызов следующего API run, а raw tool повторно добавлял весь этот run.

Независимая сверка реальных snapshots подтвердила: первые пять сводок до error показывали 24 вызова, а API содержит 23 уникальных work IDs. Сумма их terminal durations — 55329 ms → 55.3s. Snapshot API и DOM получены в разные моменты продолжающегося хода; сравнивается именно неизменившаяся первая область до error, не весь растущий тред. Приватные текст/HTML/API остаются в thread storage и не публикуются.

## Локальное исправление

DOM-соседние инструменты получают одну сводку, когда их API source — один sibling list, а промежуток содержит только collapsible work или завершённое reasoning. Длительность reasoning не служит порогом. Видимая reasoning-строка, сообщение, delegation/workflow/approval, ручная остановка, неизвестная граница или virtualization spacer сохраняют разделение. Исходные API runs остаются отдельными для безопасного сопоставления spacers.

Общие count/time/status считаются по UNION уникальных tool IDs. Пока хотя бы один вызов pending, время всей сводки отсутствует. Если разные видимые parts претендуют на одни API members, обе получают честный DOM fallback, включая разные group keys. Неоднозначные части не объединяются через spacer. Неполный API window не выдаётся за точный частичный итог.

Последнее явное раскрытие/сворачивание и фокус метрик сохраняются при объединении. Позднее сообщение внутри work-строки выделяется из сводки и остаётся видимым. Цитата выбирается и сохраняется по существующим правилам, но соседние API-пачки больше не тиражируют её.

## Test scenarios

| Сценарий | Результат |
|---|---|
| Три DOM-пачки с неотображаемым завершённым reasoning | Одна цитата, общий счётчик |
| Native summary пересекается с full-run membership raw tool | UNION без повторного вызова |
| Последний run ещё выполняется | Времени нет; после terminal — общий итог |
| Объединение после исчезновения явного reasoning | Последний выбор и metrics focus сохраняются |
| Conversation/manual-stop/unknown/delegation API boundary | Разделение сохраняется |
| Pending/неизвестное reasoning | Разделение сохраняется |
| A+B1 / spacer / B2 с пересечением memberships | Отдельные DOM totals, без дублированных full-run counts |
| Поздний полезный message внутри объединённого блока | Message видим, инструментальные части разделены |

## Проверки кандидата

[89 тестов](verification/2026-10-31-quote-flood/tests.xml), strict TypeScript, build и diff check прошли. Все прежние 77 регрессий сохранены; 12 новых проверок покрывают указанные переходы. Первое выполнение новых тестов обнаружило, что прежняя fixture не задавала terminal status для system/reasoning. Новые native reasoning fixtures явно моделируют текущий API; прежние fixtures остаются неизвестными границами, защита не ослаблена.

[Адресный native frontend](verification/2026-10-31-quote-flood/native-candidate.json): isolated headless Chromium, настоящий тред исходного скриншота и его неизменённый timeline API; candidate JS/CSS подменены только в одноразовом клиенте. На 1280/390 px первая область до error содержит ровно одну цитату и `23 tools · 55.3s`; Enter открывает все её tool rows, Space скрывает, commentary/error остаются снаружи. Общий BB/runtime не менялся.

[Browser fixture](verification/2026-10-31-quote-flood/browser.json): 12 contexts, 320/390/1280 px, текст 100/200%, light/dark, общий pending→completed и клавиатура. Двенадцать PNG сняты local-ui-capture в isolated headless Chromium. CSS/типографика/серый/паддинги/линии/значки/стрелка побайтно не менялись; сохраняются родные text-subtle-foreground, spacing, border и animate-spin. На снимках один читаемый блок вместо повторных цитат.

[Точные hashes](verification/2026-10-31-quote-flood/source-hashes.txt) и [unified diff](verification/2026-10-31-quote-flood/source.diff) относятся к кандидату. Новые коммиты меняют head PR, поэтому прежняя карточка точного merge approval не применима к новой редакции.
