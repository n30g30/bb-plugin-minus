# Анимация работы и адресат PR

## Решения владельца

После приёмки исправления флуда («Теперь без флуда, оставляем») Вадик выбрал в форме: «Адресат интеграции; merge согласуется отдельно: Подготовить PR в vadikhq — рекомендую». Цель — подготовить отдельный PR в `vadikhq/bb-plugin-minus`, из текущей `bb/minus-tool-call-quotes` в `main`. Ветка и workspace сохраняются. PR #2 в `n30g30/bb-plugin-minus` не закрываем и не перенаправляем. Создание PR ждёт согласования окончательных заголовка и описания; merge и deploy отдельно не разрешены.

Затем Вадик уточнил: при замене инструментов цитатой нужен анимированный индикатор во время работы и статичный после окончания. Продолжаем принятую основу [кольцо → круг с точкой](2026-10-30-ring-arrow.md) и [одна сводка на непрерывный блок](2026-10-31-quote-flood.md). Новый словарь и новые значки не нужны.

## Проверка установленной анимации

В source `eb5f9157786c412ebf2a26fa48641617a6b53400`, bundle `a673068fb2c4b5dd` уже реализован native `--animate-spin`: разомкнутое кольцо вращается во время pending. После completed — статичный круг с точкой. Длительность скрыта до завершения цикла; выключение или повторная установка не требуются.

[Настоящий frontend](verification/2026-10-31-motion-pr/native-motion.json) проверен в isolated headless Chromium без interception JS/CSS/API и без изменения общего runtime: 390/1280 px, обычное и reduced motion. В обычном режиме у настоящего pending-кольца animationName=spin, currentTime растёт и transform меняется между кадрами; завершённая точка не имеет анимаций. При reduced motion кольцо статично, подпись «Выполняется» и отличие от завершённой точки сохраняются. Во всех четырёх contexts нет переполнения или browser errors; source/bundle и health до/после совпадают.

Предварительная проба с клоном marker внутри работающего frontend была невалидной: Minus удалил чужой marker на следующем pass. Она не считается проверкой анимации. Итоговый evidence использует только настоящие подключённые pending/completed элементы.

## Сверка навыков

`bb-plugin-workflow` / `bb-plugin-authoring`: source/app/manifest/SDK/settings/rails не менялись. Settings остаются в существующей секции Minus; нового действия для rails нет. Исполняемые байты совпадают с прежними 89 тестами, strict TypeScript, build и независимым ревью; повтор полного suite при изменениях только документации не нужен.

`impeccable` animate/polish в Operate и `frontend-design`: движение объясняет реальную работу, по окончании прекращается; переиспользуется существующий native spin с периодом 1s из computed token, собственный тайминг не вводится. Серый, размеры, отступы, разделители и стрелка сохранены. Имеющийся lifecycle паузы вне viewport/в фоне покрыт прежним тестом; новый native evidence подтверждает фактическое движение и reduced motion. Новый макет не создаётся.

Документация README/overview/встроенного навыка приведена к принятой редакции: убраны устаревшие утверждения о ссылке источника и текущих секундах во время выполнения. Указатель текущего UI в README ведёт к принятой редакции от 31 октября и связанным решениям. Внешнее описание PR готовится по полному diff относительно main собственного fork, а не только последнему исправлению.
