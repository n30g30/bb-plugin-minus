# Проверяемая установка тестов Minus

Владелец поручил восстановить работу над Minus и принять подтреды в thr_bza87x5nhg. В отдельном PR #1 сохраняются регрессионные тесты прежней строки Called N tools; поведение установленного плагина не меняется.

На опубликованном 4ece531376a6ba926eeeca42c6e4ed8696b5261a чистая установка зависимостей проходила, четыре DOM-теста работали, но обычный TypeScript с skipLibCheck=false отказывал на missing better-sqlite3/hono. Добавлены только devDependencies @types/better-sqlite3 и hono и их lockfile-записи. Диапазоны соответствуют peerDependencies SDK 0.6.79: ^7.6.12 и ^4.11.9. SDK и runtime не обновлялись.

## Проверка

После npm ci --ignore-scripts пройдены четыре DOM-теста и обычный tsc --noEmit --pretty false; bb plugin build выполнен на BB 0.48.0. Скрипты установки пакетов не запускались: нативный backend в этих DOM-тестах не используется. Изолированная сборка создаёт артефакт SDK 0.6.94; pin исходных деклараций остаётся 0.6.79. Git diff --check прошёл.

Независимый reviewer thr_vkbxikx634 проверил точные package.json SHA-256 08f8082b929bc1527c9a0adf7ec7ecdf4c801ed0111079e1d088d496439b91d7 и package-lock.json dbda931da311ca5a28ef7bed05308665a2ab127e5555e7a13a98c02e85c6c03e: замечаний нет. Восстановленные байты повторно сверяются перед публикацией.

Доказательства находятся в текущем thread storage: minus-pr1-tests.xml, minus-pr1-tsc-fixed.log, minus-pr1-build.log. До изменения ветка совпадала с опубликованным SHA выше; новый diff воспроизводится через git diff 4ece531376a6ba926eeeca42c6e4ed8696b5261a -- package.json package-lock.json и этот новый файл.

## Границы

PR #2 с цитатами использует другую версию тестов того же модуля. Эти PR не следует сливать вслепую друг за другом: исторические ожидания Called N tools потребуют согласования с новым цитатным поведением. Этот dependency fix не объединяет PR и не меняет ни одно ожидание.

Установка кандидата, reload, merge и deploy не выполнялись. GitHub Actions workflows в fork/upstream отсутствуют; локальные проверки не являются CI. Тексты описаний PR требуют отдельного согласования перед внешней правкой. Откат этого исправления — revert соответствующего dependency-коммита; глобальные настройки не затронуты.
