# Цитаты в свёрнутых вызовах Minus

## Задача и решение

Цель изменения (2026-10-28): добавить в Minus случайную локальную русскую цитату к свёрнутым вызовам инструментов и подготовить отдельный PR к проверке. Свёрнутая группа показывает короткий курсивный текст, автора и ссылку на источник; кнопка сохраняет раскрытие/сворачивание и доступное имя со счётчиком. Источники загружаются из локального кода, сетевого запроса при показе нет.

Изменение оформляется отдельно от PR #1 с регрессионными тестами. Настройка `collapseToolCalls`, группировка, виртуализация, SDK, серверная часть, иконка и другие переключатели не меняются.

## Реализация

- `quotes.ts` содержит 200 русских переводов и восемь источников открытых англоязычных текстов Project Gutenberg; запись хранит исходный фрагмент и локатор строки.
- `group-tools.ts` показывает цитату в существующей компактной строке, добавляет отдельную ссылку на источник и оставляет количество и действие в доступном имени кнопки.
- `group-tools.test.mjs` проверяет поведение DOM, виртуализацию, ссылки и структуру подборки; `jsdom` добавлен как dev dependency.
- Обновлены описание настройки, README, обзор плагина и инструкция Minus.

## Проверки и ограничения

- Сверка источников: 200/200 исходных фрагментов сопоставлены с заявленными строками; SHA-256 всех восьми файлов совпадает с манифестом проверки.
- Сохранённый JUnit содержит 11 пройденных DOM-тестов и 0 ошибок. Включены сценарии для 1, 2 и 3 смонтированных строк и отдельная виртуализированная строка.
- Предыдущий исполнитель сообщил о проходе TypeScript, `bb plugin build .` и `git diff --check`; после этих прогонов исходный код не менялся.
- Независимый проверяющий повторно сопоставил девять исправленных переводов с английскими исходными фрагментами; полного редакторского аудита всех 200 переводов нет.
- Встроенный Impeccable detector просканировал только `.ts` regex-правилами и указал, что этот результат неполный. Установленная команда `polish` отсутствует.
- Визуальный рендер не проверен: установленный Minus остаётся на upstream `v0.2.1` (`bffa4ad`), а `local-ui-capture` не находит Playwright в `node_modules` этого checkout. Общий host не менялся.
- Проектные инструкции не найдены в checkout; попытка чтения `vadikhq/IDE/projects/bb-plugin-minus.md` завершилась 404. GitHub Actions workflow отсутствуют и не запускались.

## Стадия и откат

Изменения пока только в локальной ветке `bb/minus-tool-call-quotes`, от `main` `bffa4ad0995a5ec950bcd6a29ffe852eb0203ed6`. `pr-binding preflight --local-edits` вернул READY; remote-ветки и PR пока нет. Требуются независимое ревью точной редакции и проверка видимого результата. Точный PR body должен быть показан Вадику до создания PR. Merge требует отдельного подтверждения для URL, SHA, base и метода.

Если поведение нужно отменить после слияния, сделать revert feature-коммита. До слияния не удалять ветку или PR без отдельного согласования.
